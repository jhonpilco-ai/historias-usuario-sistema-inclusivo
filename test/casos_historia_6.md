# Casos de Prueba - Sistema Inclusivo

## Historia de Usuario 6: Compatibilidad con Navegadores

**Módulo:** Interfaz web  
**Rol involucrado:** Usuario  
**Tipo de prueba:** Prueba de compatibilidad

Esta historia valida que el sistema pueda ejecutarse correctamente en diferentes navegadores manteniendo su funcionalidad y diseño.

---

# Caso de Prueba Positivo

## ID del caso de prueba

TC-011

## Título

Acceso correcto al sistema desde diferentes navegadores

## Objetivo

Validar que la aplicación funcione correctamente en los navegadores soportados.

## Precondiciones

- El sistema debe estar desplegado correctamente.
- Los navegadores deben estar instalados.
- Debe existir conexión a internet o acceso al servidor local.

## Datos de prueba

| Campo | Valor |
|---|---|
| Navegador 1 | Google Chrome |
| Navegador 2 | Microsoft Edge |
| Navegador 3 | Mozilla Firefox |
| Funcionalidades probadas | Inicio de sesión y navegación |

## Pasos de ejecución

| Paso | Acción |
|---|---|
| 1 | Abrir la aplicación en Google Chrome |
| 2 | Ingresar al sistema |
| 3 | Verificar la interfaz y funcionalidades |
| 4 | Repetir el proceso en Microsoft Edge |
| 5 | Repetir el proceso en Mozilla Firefox |

## Resultado esperado

El sistema debe funcionar correctamente en todos los navegadores establecidos manteniendo su diseño y funcionalidades.

## Resultado obtenido

Pendiente de ejecución.

## Estado

🟡 Pendiente

## Notas / Evidencias

Se agregarán capturas del sistema ejecutándose en cada navegador.

---

# Caso de Prueba Negativo

## ID del caso de prueba

TC-012

## Título

Fallo de visualización en navegador no compatible

## Objetivo

Validar el comportamiento del sistema cuando se ejecuta en un navegador no soportado.

## Precondiciones

- El sistema debe estar disponible.
- Debe utilizarse un navegador diferente a los soportados.

## Datos de prueba

| Campo | Valor |
|---|---|
| Navegador utilizado | Navegador no compatible |
| Acción realizada | Acceso al sistema |

## Pasos de ejecución

| Paso | Acción |
|---|---|
| 1 | Abrir la aplicación en un navegador no soportado |
| 2 | Intentar acceder al sistema |
| 3 | Revisar la interfaz mostrada |
| 4 | Validar mensajes o errores presentados |

## Resultado esperado

El sistema debe informar posibles problemas de compatibilidad o mantener una respuesta adecuada sin afectar la información.

## Resultado obtenido

Pendiente de ejecución.

## Estado

🟡 Pendiente

## Notas / Evidencias

Se agregará evidencia del comportamiento encontrado.

# Sistema Inclusivo - Historias de Usuario

Este repositorio contiene la documentación de las historias de usuario y sus respectivos criterios de aceptación para el proyecto **Sistema Inclusivo**. La documentación fue elaborada siguiendo la metodología ágil **Scrum** y está basada en los requerimientos identificados durante el desarrollo del sistema.

## Contenido

* Historias de usuario.
* Criterios de aceptación.
* Descripción de las funcionalidades principales.
* Referencia al tablero Scrum utilizado para la planificación y seguimiento del proyecto.
